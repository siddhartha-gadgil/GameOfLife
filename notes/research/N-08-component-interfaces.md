## Purpose and scope

A machine is assembled from components (guns, eaters, reflectors, gates, memory cells) that
interact only through spaceships crossing their boundaries. To prove a theorem about every
program (`N-15`) the proof must be compositional: each component is verified once in isolation
against an interface, and a general theorem composes interfaces.

## Dependencies

## Sources and prior work

`S-07` §3.3–§4.4 (read): the GOL-IO semantics.

- `io_step c S₁ S₃`: a step with a *modifier* `c` giving an area the pattern must stay inside,
  assertions that a given content appears in a given area, and insertions/deletions at ports.
- `circuit_run area ins outs init`: the pattern `init` can run forever under the modifiers
  generated by input and output signal streams.
- Composition theorem for disjoint areas with matching ports, and an internalization theorem
  deleting matched input/output pairs; an infinitary version tiles `ℤ²`.
- Signals are functions `ℕ → Bool` (one bit per 60-generation tick); "approximate signals" are
  sets of streams used to absorb delay mismatches.

## Theory development

Questions this note must settle:

1. **Adopt or adapt GOL-IO?** It is proved to work for tiled LWSS logic. Our constructions also
   need components whose geometry changes over time (a sliding block that moves arbitrarily
   far), and one-shot signals (a single glider salvo) besides clocked streams.
2. **Finite support.** `S-07` composes infinitely many tiles; we compose finitely many
   components, with an explicit empty exterior. The exterior must be shown to stay empty
   (nothing escapes), or escaping gliders must be listed as outputs.
3. **Unbounded time.** Statements are invariants over all `n`, as in `N-07`.
4. **Timing abstraction.** Exact arrival times versus tolerance windows; clocked (period 30 or
   60) versus asynchronous (signal-driven, as in stable circuitry) designs. The choice interacts
   with `Q-7`.
5. **Rectangular regions or general sets** as ownership areas; how a moving block's region is
   described.

Candidate minimal formulation: a component is a triple (region, internal state family, port
list); its specification is a transition relation on (internal state, pending port events) with
a duration, proved by certificates on the region with a margin; composition follows from
`N-04` items 1 and 4. Compare with GOL-IO on the gun-plus-eater example before deciding.

## Lessons and proposal (2026-11-14)

Two component-style theorems are now compiled without any interface layer: the Gosper gun for
all time (`gosperGun_evolve`) and the block reactions for every position (`pull`, `push`). Both
proofs have the same three parts, which suggests what the interface should package.

1. **A certificate at a reference placement**, for a fixed number of generations
   (`gosperGun_evolve_sixty`, `pull_zero`).
2. **A confinement statement for every intermediate generation**: where the evolving pattern is
   while the certificate runs (`gosperGun_snd_le`, `pullSalvo_snd`). In both proofs a bound on
   one coordinate was enough, and it was obtained by one `life_eval` per generation.
3. **Independence along a run** (`Rule.evolve_union_of_forall_sep`) against everything else,
   using only the confinement statements, followed by translation equivariance.

Proposal (to be tested before it is formalized):

- **Reaction record.** `Reaction P Q n box`: `conway.evolve n P = Q` together with
  `∀ i ≤ n, conway.evolve i P ⊆ box i`, where `box i` is a rectangle (or a finite union of
  rectangles) of cells. Still lifes, oscillators, spaceships in flight and one-shot reactions
  are all instances.
- **Parallel composition.** If the boxes of two reactions are at Chebyshev distance greater than
  2 at every time, the union of the patterns is a reaction with the union of the boxes. This is
  `Rule.evolve_union_of_forall_sep` plus a lemma that separated boxes give `Sep 2`
  (`sep_of_snd_lt` is its one-coordinate case).
- **Sequential composition.** `Reaction P Q n box` and `Reaction Q R m box'` give
  `Reaction P R (n + m)` (`Rule.evolve_add`).
- **Placement.** Reactions are transported by every symmetry of the grid
  (`Rule.evolve_map`), so one certificate serves all positions and orientations.
- **Signals.** A signal is a spaceship with a lane and a phase; its flight is a reaction whose
  box moves linearly (`evolve_flight` is the instance for one direction against a still life).
- **Certificates should deliver the boxes.** The `Evolves` certificate of `N-03` already
  passes through the trimmed window of every generation, so a variant of its soundness theorem
  can give `∀ i ≤ n, conway.evolve i P ⊆ box i` from the same proof term, replacing one
  `life_eval` per generation by a single certificate. This is the first implementation step.

What this does not yet cover: components that are triggered repeatedly (a register used many
times: a reaction from each of its states back to a state, which the record does express), and
timing constraints between signals ("asynchronous is not timing-free", `R-18`): these become
side conditions on the durations `n` when reactions are composed, and need an example before a
general formulation. GOL-IO (`S-07`) handles clocked streams through fixed tiles; the proposal
above is closer to a Hoare-style calculus of one-shot reactions with footprints, which fits
the gun-free register machine chosen in `N-13`.

Smallest test of the proposal: the gun with an eater (a bounded periodic assembly of two
components), or two block registers side by side receiving salvos at different times.

## First implementation (2026-11-14)

`Theory/Life/Reactions.lean` implements the reaction record with set-valued footprints and the
rules for parallel composition (`Reaction.par`, footprints `FarApart 2`), sequential composition
(`Reaction.seq`), placement (`Reaction.translate`) and enlargement (`Reaction.mono`), with still
lifes and diagonal flight as basic reactions. Test: `pull_reaction` rebuilds the block decrement
for every position from these rules and yields a footprint for the whole operation
(`pull_reaction_snd_le`: no cell below row `12 + k` is ever alive during it).

Added the same day (`Theory/Life/Boxes.lean`): rectangular footprints `Box a b lo hi` with
`Box.farApart`, a Boolean check `boxCheck` (evaluated by `rfl`) that a window lies in a box, so
that `life_eval` plus `coe_ofRows_subset_box rfl` gives the box of each generation, and flight
with a moving box for any period and direction (`reaction_flight_box`), tested on the glider.

Certificates deliver the boxes (`Theory/Life/BoxCert.lean`): `EvolvesIn` is `Evolves` with one
Boolean box check per generation, `EvolvesIn.reaction` its soundness, and the tactic
`life_reaction` proves `Reaction S T n (fun _ => Box a b lo hi)` directly; `Reaction.seq_const`
chains parts. First use: the 1170-generation `pullGenerator_reaction`, in nine parts.

Still open: symmetries other than translations in `Reaction`; timing side conditions between
signals; a multi-component example.
