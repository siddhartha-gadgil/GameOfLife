The Game of Life is undecidable

There is a cell such that no algorithm decides, from a finite starting pattern, whether that cell is ever alive. Every pattern below is explicit, and every behaviour is a theorem checked by Lean.

The theorem

Conway’s Game of Life: every cell of the infinite grid is alive or dead; a dead cell with exactly 3 live neighbours is born, a live cell with 2 or 3 survives, all others die. Starting from finitely many live cells:

/-- **Undecidability of the Game of Life.** There is a cell `c` such that it is not computable,
from the finite initial pattern, whether `c` is alive at some generation. -/
theorem exists_not_computablePred_everAlive' :
    ∃ c : Cell, ¬ ComputablePred fun w : WindowData => EverAlive c w.cells :=
  exists_not_computablePred_everAlive_of_decSepRest fun _ hp _ => dsep_rest hp

Axioms: propext, Classical.choice, Quot.sound only. No sorry, no decide. Every concrete evolution, some of them tens of thousands of generations long, is checked in Lean’s kernel.

Life computes every partial recursive function

The other half of “Turing complete”: one fixed Life machine, with the code and the input placed in a register, halts exactly when the computation does, and from some generation on the output can be read off the block of register 0 by an explicit, computable decoder.

theorem life_universal :
    ∃ (c : Cell) (f : Nat.Partrec.Code → ℕ → WindowData) (decode : Finset Cell → ℕ),
      Computable₂ f ∧ DecodeComputable decode ∧
      ∀ code n, ((code.eval n).Dom ↔ EverAlive c (f code n).cells) ∧
        ∀ m ∈ code.eval n, ∃ T, ∀ t ≥ T, decode (conway.evolve t (f code n).cells) = m

The ingredients

Kernel

Cells are ℤ × ℤ, configurations are finite sets, conway is B3/S23. Sanity checks pin the meaning down: the block is still, a singleton dies, the rule is neither monotone nor additive.

Certificates

One generation of a row of cells is a bit-parallel adder formula. Untrusted code proposes a proof term with one kernel fact per row per generation, and the kernel checks it.

Reactions

Reaction P Q n F: P becomes Q in n generations inside a footprint. Far-apart reactions run in parallel; reactions chain in sequence and translate.

Signals and gates

Gliders carry signals; guns, eaters, OR gates and reflectors route them; a dispatch station returns an answer to the caller.

Registers

A register is a block on a diagonal, moved by glider salvos. The value is the block position plus the salvos still in flight.

Assembly

Affine formulas place the pieces of every program. Separation conditions are proved for every program, after earlier versions were refuted in Lean.
